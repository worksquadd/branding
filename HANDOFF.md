# Handoff

Недавняя работа: проект упрощён до простой файловой витрины `assets/` без React, Vite, сборки и зависимостей. Локальный сервер показывает папку сразу в стиле directory listing; постоянный центрированный заголовок — `Worksquad Branding`.

Последний запрос пользователя: напрямую показывать `assets/` в стиле server directory listing, без промежуточной страницы, с центрированным заголовком.

Дальше: материалы складывать в `assets/`; `serve_assets.py` покажет их автоматически. Правила скрытия находятся в `assets/.ignore` (сейчас `.*`, `.` и `..`). В listing отображаются только названия; файлы скачиваются по клику, папки открываются.
